# MailRu Drive Transfer

MailRu Drive Transfer is a personal tool that copies files from Mail.ru Cloud to Google Drive using rclone on the account owner's Mac.

The account owner chooses the source and destination and authorizes access through Google OAuth. The tool lists folders, uploads files, skips matching files on subsequent runs, and checks file sizes after copying. It can resume after the Mac wakes or the owner logs back in.

The configured transfer copies current files and folders. It does not migrate sharing permissions or file version history.
